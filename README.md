# VORTEXER

C++17 / SDL2 で個人制作した2D見下ろし型アクションゲームです。制作期間は約4か月です。

> このリポジトリは採用選考でのソースコード確認用です。ゲーム本体の画像・音声等のアセットは、公開再配布の権利確認を簡潔にするため含めていません。

## アプリケーションのコンセプト

ブーストを使った高速移動と、オート／マニュアル照準を切り替える戦闘を軸にした見下ろし型アクションです。殲滅・破壊・防衛など複数のミッション形式を用意し、敵編成や増援、武器性能をデータから調整できる構成にしています。

## 設計のコンセプト

ゲームの機能追加と調整を行いやすくするため、ゲーム内オブジェクトを `Actor`、機能を `Component` として分離しました。タイトル、拠点、ショップ、ミッション、戦闘、リザルト等は `Scene` 派生クラスとして切り替えています。ミッション・敵編成・武器性能はJSONから読み込み、ゲームロジックと調整データを分離しています。

技術的に工夫した点
---

### Actor / Component

描画、移動、当たり判定、HP、AI、武器などをComponentとして分け、Actorへ組み合わせる構成にしています。ActorがComponentを所有し、GameがActorの寿命を管理します。

### データ駆動

ミッション配置、報酬、敵編成、増援、武器性能をJSONから読み込みます。ゲームロジックを変更せずに数値や編成を調整できるようにしています。

### 弾丸のObject Pool

通常弾は `ObjectPool<Bullet>` を利用して確保領域を再利用し、射撃のたびにヒープ確保が発生しにくい構成にしています。

## 現時点で認識している改善点

* `Game.cpp` と `Scenes.cpp` に責務が集まっており、規模拡大時はゲーム進行・リソース管理・生成処理などをさらに分離したいです。
* 弾丸の当たり判定は敵・味方候補を線形に走査しているため、オブジェクト数が大きく増える場合はグリッド等の空間分割で候補数を絞る余地があります。
* `EnemyFactory` の型分岐は文字列による分岐が増えているため、登録テーブル等へ置き換えることで追加時の変更箇所を減らせます。

これらは、短期間で遊べる作品を完成させることを優先した結果として残っている課題です。今後規模を拡張する場合に、性能・保守性の両面から改善したい点として認識しています。
